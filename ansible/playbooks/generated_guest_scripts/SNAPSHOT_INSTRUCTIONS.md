# CAPEv2 Guest VM Snapshot Instructions

Generated by Ansible — 2026-07-26T01:35:12Z

## Prerequisites

- Windows guest VM installed and booted
- Guest VM connected to the `virbr1` bridge (192.168.1.0/24)
- These scripts have been transferred to the guest VM
  (e.g., via SMB share, USB, or shared folder)

## Step-by-Step

### 1. Harden the Guest

Open **PowerShell as Administrator** and run:

```
Set-ExecutionPolicy Bypass -Scope Process -Force
.\harden.ps1
```

Or if PowerShell is not available, run as Administrator:

```
harden.bat
```

A reboot is recommended after hardening.

### 2. Install Dependencies

After reboot, open **PowerShell as Administrator** and run:

```
.\install_deps.ps1
```

This installs Python 3.11.4, VC++ redistributable,
and required Python packages (pillow, pywintrace).

### 3. Configure the Agent

Copy `config.ini` to `C:\ProgramData\cape\config.ini`.
Adjust `ip` and `port` if your result server uses a different address.

### 4. Deploy the Agent

Copy `agent.py` from the CAPEv2 host (`/opt/CAPEv2/agent/agent.py`)
to the same directory as `deploy_agent.ps1`, then run:

```
.\deploy_agent.ps1
```

This copies `agent.py`, registers it as a Windows service named `CAPEAgent`,
starts the service, and tests TCP connectivity to `192.168.1.1:8000`.

To remove the agent later, run:

```
.\uninstall_agent.ps1
```

### 5. Shut Down and Snapshot

Once the agent is running and connectivity is confirmed:

1. Shut down the guest VM cleanly.
2. On the CAPEv2 host, create a libvirt snapshot:

```bash
virsh snapshot-create-as <vm-name> \
    --name "clean" \
    --description "Freshly hardened and agent-installed" \
    --disk-only --atomic
```

If you prefer a full (RAM + disk) snapshot:

```bash
virsh snapshot-create-as <vm-name> \
    --name "clean" \
    --description "Freshly hardened and agent-installed"
```

### 6. Update kvm.conf

On the CAPEv2 host, edit `/opt/CAPEv2/conf/kvm.conf` and set:

```ini
machines = <vm-name>
interface = virbr1
ip = 192.168.1.1
snapshot = on
```

## Troubleshooting

- If `deploy_agent.ps1` fails to connect, verify that `cape-rooter` and
  `cape` services are running on the host.
- If the agent service crashes, check Windows Event Viewer and the agent
  log file at `C:\ProgramData\cape\agent.log`.
- Ensure port `8000` is reachable from the guest.
